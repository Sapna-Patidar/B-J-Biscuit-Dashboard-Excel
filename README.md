# B&J Biscuit Dashboard - Excel

Interactive Excel dashboard analyzing B&J Biscuit sales performance and key business insights.

## Project Overview

This project analyzes B&J Biscuit sales data to understand sales performance, product trends, and key business metrics.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Visualization

## Key Insights

- Analyzed overall sales performance.

- Used interactive filters to explore the data.
- Created visualizations to support business decision-making.
